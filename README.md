# Linked List Management System

A menu-driven Java application demonstrating core data structure operations on **Singly Linked Lists (SLL)** and **Doubly Linked Lists (DLL)**. This project includes implementation of dynamic insertions, deletions, traversals, algorithms (reversal, sorting, duplicate removal), and utility functions.
